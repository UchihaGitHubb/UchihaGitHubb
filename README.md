## 🚀 Featured projects

### [Wanderlux — travel agency website](https://www.wanderlux.co)
Freelance · Aug – Oct 2026 · *Client project — source code is private*

Complete redesign of the website of a travel agency in Cali, Colombia: 42 pages with services, travel packages, a blog and a US visa service page.

- **Stack:** Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS v4, Vercel, GitHub Actions
- Technical SEO on every page: canonical URLs, Open Graph images, sitemap and JSON-LD structured data
- Custom hero carousel with autoplay, swipe gestures, keyboard navigation and `prefers-reduced-motion` support
- Mobile-first and accessible (44 px tap targets), with sales funnels to WhatsApp and an online booking engine
- CI with GitHub Actions and preview deployments for every pull request

### Lex Virtual — VR training platform for law students
University team project · 2025 · [API](https://github.com/UchihaGitHubb/lex-virtual-backend) · [Web dashboard](https://github.com/UchihaGitHubb/lex-virtual-web) · [Unity VR app](https://github.com/UchihaGitHubb/lex-virtual-unity)

Students practice legal cases in virtual reality; the app measures their performance and nervousness, and teachers review the results and give feedback.

- **Backend:** NestJS, TypeORM, PostgreSQL, JWT with roles (student / teacher), Swagger, audio uploads
- **Frontend:** React Router 7, React 19, TypeScript — teacher dashboard with student tracking and charts
- **VR:** Unity with XR Interaction Toolkit, connected to the same REST API

### [Galería Alameda — market guide app](https://github.com/UchihaGitHubb/Galeria_alameda_hd)
Personal project · 2026

Mobile web app to explore the Galería Alameda market in Cali: interactive map with zoom, zones, vendors, search by category, routes and favorites.

- **Stack:** React 19, React Router, JavaScript
- Spanish / English, light and dark themes, onboarding and authentication screens
